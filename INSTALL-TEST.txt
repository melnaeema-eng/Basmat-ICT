BASMAT ICT — INVOICE MERGE V1.6
================================
هدف هذه النسخة: دمج الخصائص بدون استبدال عشوائي:
- نموذج الفاتورة الحالي + بيانات VAT/CR/العنوان.
- QR + Verification Code للفاتورة.
- توقيع الشركة + اعتماد العميل في الطباعة.
- قبول/اعتماد الفاتورة من بوابة العميل.
- صفحة عامة للتحقق: /verify-invoice/:token
- لا تعديل على PortalRequests ولا AdminCustomers ولا Quotations.

1) تركيب الملفات:
cd C:\projects\Basmat-ICT

Expand-Archive `
  -Path "$env:USERPROFILE\Downloads\BASMAT-ICT-INVOICE-MERGE-V1.6.zip" `
  -DestinationPath . `
  -Force

2) Supabase SQL Editor:
نفذ الملف:
supabase/INVOICE_VERIFICATION_ACCEPTANCE_V1_6.sql

المتوقع في آخر نتيجة:
invoice_v1_6_health = PASS

3) تشغيل محلي:
npm run dev

4) اختبار Admin:
- افتح فاتورة صادرة.
- تأكد من ظهور بيانات البائع والعميل.
- تأكد من Verification Code وQR.
- تأكد من وجود Authorized Signature وCustomer Acceptance.
- افتح QR أو /verify-invoice/<token> وتأكد من صفحة التحقق.

5) اختبار Portal:
- ادخل بحساب العميل المرتبط بالفاتورة.
- افتح /portal/invoices
- يجب ظهور الفاتورة حتى لو كانت مدفوعة.
- اضغط "قبول / اعتماد الفاتورة".
- بعد الاعتماد يجب ظهور حالة "مقبولة ومعتمدة" وتاريخ الاعتماد.
- افتح/اطبع الفاتورة وتأكد من ظهور الاعتماد.

6) Build قبل GitHub:
npm run build

لا ترفع GitHub إذا ظهر أي Error في build أو الاختبارات.
