BASMAT ICT — QUOTATION EXPORT EXCEL + WORD
===========================================

TARGET
C:\projects\Basmat-ICT

ADDED
- Excel Arabic export
- Excel English export
- Word Arabic export
- Word English export
- Includes customer information, quotation items, discount, VAT, totals, notes, terms, bank details, and verification code.
- No SQL/database changes.
- No new npm packages required.

NOTE
The exported files are Microsoft Office-compatible formats:
- Excel: .xls
- Word: .doc
They open directly in Microsoft Excel and Microsoft Word and can be re-saved as .xlsx/.docx if required.

INSTALL
cd C:\projects\Basmat-ICT

Expand-Archive `
  -Path "$env:USERPROFILE\Downloads\BASMAT-ICT-QUOTATION-EXPORT-EXCEL-WORD.zip" `
  -DestinationPath . `
  -Force

TEST
npm run dev

Open any saved quotation and verify the new buttons:
- Excel عربي
- Excel English
- Word عربي
- Word English

Then test a quotation with discount and long descriptions.

BUILD
npm run build

After PASS:
git add .
git commit -m "Add quotation Excel and Word export"
git push origin main
