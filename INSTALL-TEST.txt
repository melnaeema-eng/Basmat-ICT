BASMAT ICT — PORTAL ADMIN BUTTON
=================================

PURPOSE
A user who is BOTH:
- an active Customer Portal user, and
- an active/non-archived ict_admin_users user

will see:
"لوحة الإدارة"

in the Customer Portal header.

Normal customers will NOT see the button.

SECURITY
The button itself is not the security control.
Existing /admin ProtectedAdminRoute + permissions + MFA remain the actual protection.
The browser does NOT directly query ict_admin_users; it calls a small secure RPC.

STEP 1 — INSTALL
cd C:\projects\Basmat-ICT

Expand-Archive -Path "$env:USERPROFILE\Downloads\Basmat-ICT-HOTFIX-Portal-Admin-Button.zip" -DestinationPath . -Force

STEP 2 — SQL
Run in Supabase SQL Editor:
supabase/PORTAL_ADMIN_ACCESS_BUTTON.sql

Expected:
PORTAL ADMIN ACCESS RPC | PASS ✅

STEP 3 — TEST
npm run dev

TEST A — Authorized dual-role user
1. Login through /portal/login.
2. User must exist in ict_customer_portal_users.
3. Same auth user_id must exist in ict_admin_users and be active.
4. "لوحة الإدارة" must appear in portal header.
5. Click it.
6. Existing admin authorization/MFA must apply normally.

TEST B — Normal customer
1. Login with a customer who is NOT in active ict_admin_users.
2. "لوحة الإدارة" must NOT appear.
3. Direct /admin access must still be blocked by existing admin protection.

FINAL
npm run build
