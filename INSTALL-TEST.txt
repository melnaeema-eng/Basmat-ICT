BASMAT ICT — QUOTATION V3
Discount + Arabic / English
================================

IMPORTANT ORDER
1) Run Supabase SQL first:
   supabase/QUOTATION_V3_DISCOUNT_AR_EN.sql
   Both health checks must return PASS.

2) Extract ZIP into project root:
   C:\projects\Basmat-ICT

PowerShell:
cd C:\projects\Basmat-ICT
Expand-Archive -Path "$env:USERPROFILE\Downloads\BASMAT-ICT-QUOTATION-V3-DISCOUNT-AR-EN.zip" -DestinationPath . -Force

3) Test locally:
npm run dev

TEST CASE
- Open/create quotation.
- Fill Arabic + English subject.
- Fill Arabic + English item description and unit.
- Enter subtotal items.
- Try Discount = Percentage 10%.
- Verify: Subtotal -> Discount -> Net Before VAT -> VAT -> Total.
- Try Discount = Fixed Amount.
- Save/reopen quotation and verify values persist.
- Click "طباعة عربي" and check RTL Arabic PDF.
- Click "Print English" and check LTR English PDF.
- Open customer portal quotation and switch Arabic/English.
- Confirm QR / Verification Code / IBAN unchanged.

4) Build:
npm run build

5) Only after PASS:
git add .
git commit -m "Add quotation discounts and bilingual Arabic English versions"
git push origin main

NOTES
- Discount is applied BEFORE VAT.
- VAT is calculated on Net Before VAT.
- Existing quotations remain compatible.
- Existing quotation number, QR, verification token/code, IBAN and workflow are preserved.
