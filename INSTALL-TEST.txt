BASMAT ICT — QUOTATION PRINT V2 CORPORATE
==========================================

TARGET
C:\projects\Basmat-ICT

WHAT CHANGED
- New dedicated Corporate Print layout for quotation.
- Editor screen remains unchanged.
- Print no longer uses form inputs/textareas.
- Font overlap fixed by controlled Arial/Tahoma print typography and line-height.
- Customer information displayed as clean document fields.
- Professional quotation header with number, date, validity and currency.
- DESCRIPTION receives 43% of table width.
- Full multi-line description wraps without clipping.
- Balanced QTY / UNIT / UNIT PRICE / TOTAL / VAT / TOTAL VAT INCLUDED columns.
- Clear Financial Summary with highlighted Grand Total.
- Notes and Terms are printed as full text blocks.
- Bank Details preserved with Al Rajhi IBAN.
- QR Verification and verification code preserved.
- Signature areas and corporate footer included.
- No SQL or database changes.

INSTALL
cd C:\projects\Basmat-ICT

Expand-Archive `
  -Path "$env:USERPROFILE\Downloads\BASMAT-ICT-QUOTATION-CORPORATE-V2.zip" `
  -DestinationPath . `
  -Force

RUN
npm run dev

TEST
1) Open a quotation with a long DESCRIPTION (several lines).
2) Add several items.
3) Add long Notes and Terms.
4) Click Print and inspect Print Preview.
5) Confirm no overlapping text and all 8 columns are visible.
6) Confirm QR, IBAN and footer are visible.

BUILD
npm run build

git add .
