BASMAT ICT - PORTAL NEW REQUEST V1.5

GOAL
Add clear "new request" actions inside Customer Portal > Requests without changing database schema.

CHANGED FILE
src/pages/Portal/PortalRequests.jsx

INSTALL
1) Close the dev server if it is running.
2) From PowerShell:

cd C:\projects\Basmat-ICT
Expand-Archive `
  -Path "$env:USERPROFILE\Downloads\BASMAT-ICT-PORTAL-NEW-REQUEST-V1.5.zip" `
  -DestinationPath . `
  -Force
npm run dev

TEST
1) Login as a customer.
2) Open /portal/requests.
3) Confirm these buttons appear:
   - + طلب عرض سعر جديد
   - + طلب استشارة جديدة
4) Click طلب عرض سعر جديد -> /quote.
5) Submit a test request and confirm it returns/appears in طلباتي according to the existing RFQ flow.
6) Click طلب استشارة جديدة -> /consultation and test the same way.

NOTES
- No SQL required.
- Existing RFQ/Consultation forms and RLS are reused.
- Existing request list behavior is preserved.
- Build was not run in this packaging environment; run npm run build locally after functional testing and before GitHub push.
