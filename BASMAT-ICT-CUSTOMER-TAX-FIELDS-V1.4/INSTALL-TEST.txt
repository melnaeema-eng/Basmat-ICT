BASMAT ICT - CUSTOMER TAX FIELDS V1.4
====================================

الهدف
-----
إضافة بيانات العميل الضريبية/التجارية إلى شاشة إضافة وتعديل العملاء، وحفظها في ict_customers.

الحقول
------
- vat_number       الرقم الضريبي
- cr_number        السجل التجاري
- billing_address  عنوان الفوترة / العنوان المسجل

مهم
----
الرقم الضريبي اختياري، لكن إذا تم إدخاله من الشاشة يجب أن يكون 15 رقمًا.
لا يتم فرض الرقم الضريبي على الأفراد أو العملاء غير المسجلين في ضريبة القيمة المضافة.

1) فك الضغط داخل المشروع
-------------------------
cd C:\projects\Basmat-ICT

Expand-Archive `
  -Path "$env:USERPROFILE\Downloads\BASMAT-ICT-CUSTOMER-TAX-FIELDS-V1.4.zip" `
  -DestinationPath . `
  -Force

2) Supabase
-----------
افتح SQL Editor وشغّل الملف:
supabase/CUSTOMER_TAX_FIELDS_V1_4.sql

المتوقع:
customer_tax_fields_health = PASS

3) تشغيل محلي
-------------
npm run dev

4) اختبار
---------
- افتح: Admin > العملاء
- اختر إضافة عميل
- تأكد من ظهور:
  * الرقم الضريبي (15 رقم)
  * رقم السجل التجاري
  * العنوان / عنوان الفوترة
- احفظ عميلًا جديدًا.
- افتح نفس العميل للتعديل وتأكد أن القيم رجعت كما حفظتها.
- جرّب رقم ضريبي أقل/أكثر من 15 رقمًا؛ يجب منع الحفظ برسالة واضحة.
- ابحث بالرقم الضريبي أو السجل التجاري؛ يجب أن يظهر العميل في نتائج البحث.

5) بعد نجاح الاختبار فقط
------------------------
npm run build

git add .
git commit -m "feat: add customer tax and commercial fields v1.4"
git push
