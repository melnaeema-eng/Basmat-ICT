# Sprint 16.2 — Staff Management

Adds:
- Auto lookup by email.
- Auto-fill staff name for existing users/customers.
- Clear indicator when the email belongs to an existing customer or staff user.
- Edit staff name and role.
- Temporary disable/reactivate.
- Archive/restore.
- Safe removal of staff access while preserving the same Auth account and customer portal account.
- Existing customer keeps the same password and customer data.

This patch does not delete Supabase Auth users.
