# Basmat ICT — Sprint 11.2

Support activity is now recorded in Admin Notifications and surfaced on the Admin Dashboard.

## Included
- Notification when customer opens a support ticket.
- Notification when customer replies.
- Notification when customer uploads an attachment.
- Support ticket/open/urgent counters on Admin Dashboard.
- Unread notification counter.
- Latest activity feed on Admin Dashboard.

## Install
1. Extract the ZIP over the Basmat-ICT project.
2. Run `supabase/sprint11_2_support_activity_notifications.sql` in Supabase SQL Editor.
3. Run `npm run dev`.
4. Test by creating/replying/uploading from the customer portal, then check `/admin` and `/admin/notifications`.
