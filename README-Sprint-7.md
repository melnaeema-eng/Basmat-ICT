# Basmat ICT — Sprint 7
## Customer Portal + Approval Workflow

### الجديد
- `/portal/login`
- بوابة عميل مستقلة.
- عرض عروض السعر الخاصة بالعميل فقط.
- قبول/رفض عرض السعر.
- سجل موافقة إلكترونية باسم الشخص المخول وتاريخ القرار.
- إشعار للأدمن بعد القبول أو الرفض.
- عرض المشاريع التشغيلية.
- عرض الفواتير والتحصيل.
- إدارة ربط مستخدمي البوابة من الأدمن.

### مهم
سجل القبول الإلكتروني هنا هو سجل موافقة داخل النظام، وليس توقيعًا رقميًا مؤهلًا بشهادة رقمية.

### التثبيت
1. فك الحزمة فوق المشروع.
2. شغّل `supabase/sprint7_customer_portal.sql`.
3. طبّق Routes الموجودة في `SPRINT7-ROUTES.txt`.
4. أنشئ أول مستخدم عميل من Supabase Authentication.
5. اربطه بعميل CRM من `/admin/portal-users`.
