# Basmat ICT Portal — Sprint 13

## Executive Dashboard & Reports

Adds a management dashboard at `/admin/executive-reports` with:
- Financial KPIs: project value, invoiced, collected, outstanding, overdue invoices.
- Sales conversion: quotations and accepted quotations.
- Project KPIs: active/completed projects and average progress.
- Customer and support snapshots.
- Period filters: month, quarter, year, all.
- Browser Print / Save as PDF.

## Installation
Overlay the ZIP on the project. No SQL migration is required in Sprint 13.

Run `npm run dev`, then open `/admin/executive-reports`.
