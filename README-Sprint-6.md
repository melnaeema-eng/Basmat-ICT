# Basmat ICT — Sprint 6
## Project & Commercial Management

### الجديد
- إدارة المشاريع بعد فوز الفرصة.
- ربط المشروع بالعميل والفرصة.
- مدير المشروع ونسبة الإنجاز.
- العقود.
- مهام المشروع.
- أوامر الشراء PO.
- فواتير العميل.
- الدفعات والتحصيل.
- Operations Dashboard.

### التثبيت
1. فك الحزمة فوق المشروع.
2. شغّل `supabase/sprint6_projects_commercial.sql` في Supabase SQL Editor.
3. أضف Routes وSidebar كما في `SPRINT6-PATCH.txt`.
4. `npm run dev`

### الاختبار
- `/admin/operations`
- `/admin/project-management`
- `/admin/project-commercial`

ابدأ بمشروع واحد، ثم عقد، مهمة، PO، فاتورة، ودفعة.
